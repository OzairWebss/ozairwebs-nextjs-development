# Reporting sensitive information

This is a documentation repository, not a deployed application or an incident-response service. If a file accidentally exposes a credential, private record or exploitable issue relating to OzairWebs, do not reproduce it in a public issue.

Contact info@ozairwebs.com with the affected path, a concise description and a safe way to reproduce the observation. Omit passwords, full customer data and unnecessary exploit details. No response-time commitment or bounty is promised here. For vulnerabilities in WordPress, WooCommerce, Next.js or a third-party extension, use that project's own responsible-disclosure channel.

General documentation inaccuracies can be reported publicly with official references. No security audit or production certification is implied by publishing these guides.
