# Contributing a documentation correction

This repository addresses https://ozairwebs.com/technologies/nextjs/. A useful contribution corrects an identifiable technical statement, adds a missing acceptance check or improves a decision readers can make.

Open an issue with the document and heading, the existing wording, the proposed correction, an official source and the version/date affected. If you submit a pull request, describe how the revised recommendation was checked. Label hypothetical examples as illustrative; separate a published case fact from an engineering inference.

Keep changes focused. Check relative links from the document's own directory. Use descriptive link labels and accessible image text. Do not add referral links, keyword lists, unsupported performance claims, generated city pages or copied client code. Never include credentials, customer records or private diagnostics. Report sensitive security information using SECURITY.md.

Original documentation contributions are accepted under this repository's CC BY 4.0 terms. Brand assets remain excluded. Maintainers may request sources, revise unclear wording or decline changes outside the subject. Commercial project enquiries belong at the official contact page, rather than in issue threads.
